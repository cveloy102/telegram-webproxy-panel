Папка Google Диска

Отдельная папка в личном Диске. Старые копии автоматически не удаляются.

Ключ восстановления

Если файл ключа у тебя уже есть, вставь прежнюю публичную строку age1… из этого файла — новый ключ создавать не нужно. При первой настройке создай и скачай ключ, затем сохрани файл вне VPS и папки с копиями. Без приватного ключа копию невозможно открыть. Сервер получает только публичную часть.

Изменения ключей, настроек и сайта объединяются в копию через 10 секунд. Трафик дополнительно сохраняется раз в сутки. При недоступности Диска — повторные попытки. На сервере остаются пять последних зашифрованных копий.

Подключить / переподключить Google Диск — инструкция

Ссылка на папку указывает, куда складывать копии. Для доступа к Диску сначала нужно войти в Google через rclone. Команды ниже выполняются на твоём компьютере Windows, не на VPS. Вводи их по одной и нажимай Enter.

  1. Открой PowerShell через «Пуск». Установи rclone:
    winget install --id Rclone.Rclone -e --source winget
    Если winget недоступен, скачай rclone с официального сайта. Для macOS и Linux используй установку с того же сайта.
  2. После установки закрой все окна PowerShell и Windows Terminal. Открой PowerShell заново через «Пуск». Это нужно, чтобы Windows увидела установленную программу.
  3. Запусти вход в Google:
    rclone authorize "drive"
    В открывшемся браузере выбери аккаунт с нужной папкой и разреши доступ. Если браузер не открылся, открой ссылку, которую напечатал rclone.
  4. Вернись в PowerShell. Между надписями Paste the following… и End paste появится блок, начинающийся с { и заканчивающийся }. Скопируй весь блок вместе с фигурными скобками. Надписи, команды и приглашение PS C:\…> копировать не нужно.
  5. Вставь блок в поле «JSON-токен rclone» ниже и нажми «Подключить Диск». Результат появится прямо под кнопкой. Само вставление текста ещё не сохраняет токен.
  6. Выше укажи ссылку на папку и публичный ключ восстановления age1…, нажми «Сохранить настройки». Затем нажми «Создать копию» и дождись подтверждённой загрузки. Сохранение токена само по себе не подтверждает загрузку файла на Диск.
PowerShell пишет «rclone не распознано»

Переустанавливать rclone не нужно. Сначала выполни эту строку:

$env:Path = [Environment]::GetEnvironmentVariable('Path','Machine') + ';' + [Environment]::GetEnvironmentVariable('Path','User')

Дождись нового приглашения PowerShell и только затем отдельно выполни:

rclone authorize "drive"

Токен даёт доступ к Google Диску: вставляй его только в свою панель, не отправляй в чат. Приватную строку AGE-SECRET-KEY-… сюда вставлять нельзя. Для старых архивов сохрани прежний файл ключа восстановления.

Google запрашивает полный доступ rclone к Диску. Панель обращается только к выбранной папке; это ограничение программы, а не разрешений Google. Токен хранится на VPS с правами только для root и попадает внутрь зашифрованной копии.

Как восстановить на другом VPS

Скачай нужный файл .tar.gz.age с Диска. Установи панель на новый VPS с прежними доменами, перенаправь их DNS на новый IP и передай архив с ключом восстановления. Открыть инструкцию восстановления →

Сохраняются прежние секреты клиентов. Подключения, в которых вручную указан старый IP, придётся изменить. Сертификаты новый сервер получает заново.
