Выход за рубежом.

Первая версия: один выходной узел, весь клиентский трафик через него. Панель и SSH остаются на RU. При обрыве каскада прямой выход клиентов через RU запрещён. IPv6 через каскад пока не поддерживается.

2. Подключить зарубежный VPS

Скопируй данные RU ниже. На отдельном чистом зарубежном VPS с Ubuntu 24.04 amd64 запусти обычный установщик и выбери «Выходной узел каскада». Домен для него не нужен. Вставь данные RU по запросу установщика и открой выбранный входящий UDP-порт в кабинете хостера.

bash <(curl -fsSL https://raw.githubusercontent.com/cveloy102/telegram-webproxy-panel/main/install.sh) --exit-node

На выходном VPS выполняется та же команда установки, что и в README проекта. Полная панель там не устанавливается. Не вставляй сюда пароль root, SSH-ключ или приватный ключ туннеля.

3. Проверить и включить

Проверка выполняет HTTPS-запрос через туннель и сверяет выходной IP с адресом зарубежного VPS. При переключении текущие подключения прервутся — клиентам потребуется переподключиться.
