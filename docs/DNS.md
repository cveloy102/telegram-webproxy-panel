# Домен → IP сервера

У тебя уже есть VPS с Ubuntu 24.04 и домен. Осталось направить выбранный адрес на сервер.

## 1. Найди IPv4 VPS

Он указан в карточке сервера у хостера. В примере ниже используется **203.0.113.10** — это адрес для документации; **замени его своим**.

## 2. Открой управление DNS домена

Нужен раздел «DNS-записи», «DNS-зона» или «Управление зоной». Если DNS обслуживает другая компания, запись создаётся там, а не обязательно у продавца домена.

Добавь запись:

| Поле | Что вписать |
|---|---|
| Тип | `A` |
| Имя / Host | `tg` |
| Значение / IP | IPv4 твоего VPS |
| TTL | По умолчанию |

Если домен `example.com`, получится **tg.example.com**. Некоторые панели просят полное имя `tg.example.com` вместо `tg` — ориентируйся на подсказку у провайдера.

Для корня домена обычно используют `@`. Проще выделить отдельный поддомен `tg`, чтобы не затронуть основной сайт.

## 3. Убери конфликтующие записи у этого поддомена

Для первой версии нужен ровно один IPv4. У выбранного `tg` не должно быть других A, AAAA или CNAME. Не удаляй записи других поддоменов, MX почты и прочие записи зоны.

В Cloudflare выбери **DNS only** — серое облако. Проксирование через CDN в этой инструкции не используется.

## 4. Дождись обновления

Это может занять время. Установщик проверит DNS и объяснит, если адрес ещё не обновился или ведёт на другой IP. Повтори команду позже.

При желании проверить с компьютера:

```text
nslookup tg.example.com
```

В ответе должен появиться IP твоего VPS. DNS-проверка сама по себе не проверяет доступность портов.

## 5. Разреши порты у хостера

В firewall / сетевых правилах VPS разреши входящие **TCP 80 и TCP 443**. Если включён UFW на самом сервере, эти порты тоже должны быть разрешены. Сохрани доступ к своему SSH-порту. Не отключай firewall целиком.

Backend-порты 2398, 8888 и внутренние порты 8080–8082 открывать наружу не нужно.

Теперь вернись к [команде установки](../README.md#-установка). В установщике укажи **tg.example.com**, без `https://` и без `/` в конце.
