# Если что-то не работает

## Домен не найден / указывает не на тот сервер

Проверь A-запись в DNS. Она должна содержать публичный IPv4 именно этого VPS. Убери лишние A / AAAA у выбранного поддомена. В Cloudflare — DNS only. Дождись обновления DNS и повтори установку.

## Порт занят / найдена существующая конфигурация

Установщик рассчитан на отдельный чистый VPS. Он не останавливает чужие сайты и VPN и не импортирует сторонние установки. Используй отдельный VPS; не удаляй чужие файлы наугад.

## Нет HTTPS / ошибка сертификата

Проверь DNS, доступность TCP 80/443 у хостера и firewall самого VPS. Для первой версии не должно быть AAAA-записи у выбранного поддомена. Не обходи предупреждение браузера о сертификате: сначала исправь причину.

Службы могут уже работать, даже если сертификат ещё не выпущен. После исправления сети повтори команду установки и выбери **«Проверить»**. Ключи и пароль останутся прежними.

Диагностика на сервере:

```bash
relay-panel status
journalctl -u caddy -n 50 --no-pager
```

## Код первого входа истёк

Пока владелец ещё не создан, получи новый код:

```bash
relay-panel setup-code
```

Если пароль уже создан, эта команда его не сбрасывает. Входи с паролем и кодом аутентификатора. При потере телефона используй один из сохранённых резервных кодов.

## Forbidden после формы

Открой адрес панели заново через адресную строку. Не отправляй повторно старую форму после обновления сервера, выхода или долгого простоя. Cookie должны быть разрешены. Проверь, что адрес начинается с `https://` и совпадает с доменом установки.

Если ошибка повторяется, сообщи версию проекта и браузер в Issue. Пароль, cookie и одноразовые коды отправлять не нужно.

## Telegram не предлагает WEB

Нужен клиент, в котором есть именно тип **WEB**. Не вводи эти параметры в MTProto или SOCKS5. Поддержка зависит от клиента и версии. Установка сервера не добавляет WEB в приложение Telegram.

## Ссылка не открылась

Ссылка использует `tg://webproxy`. На некоторых устройствах браузер не передаёт её приложению. Введи вручную тип **WEB**, сервер из окна «Ссылка / QR» и секрет. В сервере нет `https://` и порта. Никому не отправляй скриншот с рабочим секретом, кроме получателя доступа.

## Прокси доступен, но сообщения не идут

Проверь, что профиль включён и общая пауза выключена. Убедись, что клиент поддерживает WEB. VPS должен иметь исходящий доступ к Telegram. Работа зависит также от сети клиента и доступности IP VPS.

```bash
relay-panel status
journalctl -u mtproxy -u tproxy-server -n 50 --no-pager
```

Перед отправкой журналов убери IP, домены, имена и любые секреты. Не прикладывай весь каталог `/etc` и базу панели.

## После выдачи ключа все кратко переподключились

Ожидаемое поведение текущей версии: изменение набора ключей перезапускает backend и релей. Остальные ключи при этом сохраняются.

## Онлайн неточный / IP изменился

«Онлайн» — активность сессии за 90 секунд. Мобильная сеть и Wi-Fi могут менять IP. Смотри на историю и длительность события; предупреждение не доказывает утечку. Решение об отключении ключа принимаешь ты.

## Не удалось обновиться

Не запускай другие установщики поверх этой установки. Выполни `relay-panel status`, сохрани текст ошибки и проверь `/var/log/relay-panel-install.log`. При ошибке переключения версии установщик пробует откат. Если службы уже работают, а проблема только в HTTPS, исправь DNS / firewall и выбери проверку при повторном запуске.
